# Restore Frontend V1

Backup ini berisi kondisi frontend sebelum perubahan v2:

- `app`
- `components`
- `styles`
- `public`
- `package.json`
- `package-lock.json`
- `postcss.config.mjs`
- `components.json`

Untuk restore manual, salin isi folder backup ini kembali ke root project dan replace file/folder yang sama.
